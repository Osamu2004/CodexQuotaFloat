# CodexQuotaFloat

一个原生 macOS 菜单栏应用，用浮窗显示 Codex 的 5 小时与每周使用额度。

## 数据来源

应用优先启动 Mac 上已经安装的 Codex `app-server`，调用只读方法
`account/rateLimits/read` 获取实时数据。它不会保存账号、密码、Cookie 或访问令牌。

如果实时接口暂时不可用，应用会从 `~/.codex/sessions` 中读取最近一条有效额度记录，
并在浮窗中标记为“本地记录 / 数据可能已过期”。

## 功能

- 常驻菜单栏，菜单栏直接显示 5 小时额度已用百分比
- 毛玻璃悬浮窗，可拖动、靠近屏幕边缘时自动吸附
- 原生 macOS 红色交通灯关闭按钮；关闭浮窗后菜单栏仍继续运行
- 关闭按钮位于悬浮窗内容区右上角，关闭浮窗后菜单栏仍继续运行
- 关闭浮窗后再次双击应用会自动重新显示，不会停留在后台隐藏状态
- 显示 5 小时与每周窗口、剩余百分比、重置倒计时
- 新版 ChatGPT 返回多个额度桶时逐桶显示主窗口与每周窗口
- 剩余额度采用并排数字卡片，不再使用横向进度条
- 本地记录当前主额度窗口的今日消耗增量，并显示紧凑趋势折线（从安装此版本后开始累计）
- 根据同一额度窗口的采样速度估算额度耗尽时间；采样不足时明确标记
- 按自然日汇总额度消耗，菜单栏展示最近 7 天，并在本地永久保存历史
- 显示今日输入、输出和缓存 Token，并永久保存每日 Token 历史
- 将近期 Codex 线程与日志中的累计 Token 关联，显示线程级输入、输出和缓存量
- 菜单栏提供 CLI 路径、最近额度记录和任务日志错误诊断
- 悬浮窗提供“查看全部历史”按钮，可按日期浏览完整额度与 Token 记录
- 显示正在运行的 Codex 任务数量
- 自动记录“已完成、待查看”的任务，并支持逐个或全部标记已查看
- 菜单中展示最近的运行中与待查看任务标题
- 从 Codex 本地线程数据库读取真实对话名，并支持 `codex://threads/...` 直达对应对话
- 宠物风格活动托盘：动态工作状态、对话通知卡、活动堆叠和空闲状态
- 默认采用 300×304 点紧凑浮窗；活动区折叠为单行胶囊，完整列表保留在菜单栏
- 自动刷新：1 分钟、5 分钟或 15 分钟
- 浮窗透明度、显示/隐藏、鼠标穿透
- 支持登录时启动
- 实时查询失败时自动读取本地记录

## 要求

- macOS 13 或更高版本
- 已安装并登录 ChatGPT for Mac（新版桌面版已将 Codex 集成其中；旧版 Codex.app 也支持）
- Xcode Command Line Tools（仅构建时需要）

## 构建

```bash
chmod +x scripts/build-app.sh
./scripts/build-app.sh
```

构建脚本直接调用 Apple `swiftc`，不依赖第三方包。它还会运行额度协议解析测试。

构建产物位于隐藏的构建目录，避免系统把它识别为第二份已安装软件：

```text
.build-direct/CodexQuotaFloat.app
```

双击应用或执行：

```bash
open .build-direct/CodexQuotaFloat.app
```

若需要稳定使用“登录时启动”，建议把应用移动到 `/Applications` 后再打开该选项。

## 隐私说明

应用只在本机访问 Codex。源码不包含遥测、服务器上传或第三方网络请求。

任务状态来自本机 `~/.codex/sessions` 中的 `task_started` 与 `task_complete`
生命周期事件，并以 Codex 对话线程为单位去重。同一个对话中的多轮提问、命令和回复
始终只计为一个任务。“待查看”由本应用本地维护：对话的最新一轮完成后加入列表，继续
该对话时自动移除，直到再次完成或被你标记为已查看。升级到 0.2.2 时会清除旧版按轮次
累计出的错误待查看记录。

在菜单栏的“已完成，待查看”列表中点击任务，会先减少待查看数量，再打开 Codex。
Codex 当前未公开“用户在主应用中查看了哪一个本地对话”的状态，因此直接从 Codex
主界面打开对话不会自动通知本浮窗。
